Kα estimate

E ≈ 10.2 (Z−σ)² eV, λ = hc/E with hc = 1239.84 eV·nm. One screening value for both shells: a teaching estimate. Tabulated Kα₁ points: LBNL X-Ray Data Booklet, Table 1-2 (xdb.lbl.gov). Fitted σ is an empirical parameter.

Thermal radiation and the relations

B₂₁u/A₂₁ = 1/(eˣ−1), x = hν/kBT. g₁B₁₂ = g₂B₂₁ and A₂₁/B₂₁ = 8πhν³/c³, with u per unit ordinary frequency. Steady state with radiation parameter r = B₂₁u/A₂₁: N₂/N₁ = (g₂/g₁) r/(1+r), so this closed, steady-state incoherent pumping model cannot produce inversion.

Ensemble decay

Γ = A_a + A_b + k_nr, τ = 1/Γ, radiative branch b_i = A_i/Γ. Each atom decays at a random time (exponential); τ is the mean waiting time and the ensemble e-folding time. Counts scatter around the expected values: try 2000 atoms.
