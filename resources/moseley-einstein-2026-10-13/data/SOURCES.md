# Data sources

The ten Kα₁ values in `kalpha_tabulated.csv` were checked against LBNL X-Ray Data Booklet Table 1-2 on 13 October 2026.

https://xdb.lbl.gov/Section1/Table_1-2.pdf

The data are a fixed reference compilation. Precision shown is the source precision and does not establish the accuracy of the screened model. The 17.15 keV identification example is synthetic.
